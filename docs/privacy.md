# 隐私设计

- 本地 Ollama 是默认 Provider。
- 云端 API 默认关闭。
- 云端调用必须携带显式用户授权状态。
- 本地调用失败不会自动切换到云端。
- API 密钥不进入 SQLite、日志、Git 或错误消息。
- 文件内容提取只保存短摘要，不保存完整私人文档。
- 对 `.env`、私钥、证书等敏感文件，云端 AI 调用会被拒绝。
- 图片理解和云端视觉模型后续需要单独授权。

## 本地与云端

本地 Ollama 调用发生在 `http://localhost:11434`。如果用户启用 OpenAI 兼容云端 API，DiskWise 只会在业务代码显式传入授权标记后发送摘要，不会因为本地模型失败而自动回退云端。

## 后续增强

- 云端请求前移除用户名、绝对路径和不必要的上下文。
- 增加敏感关键词检测。
- 对模型调用记录只保存摘要和耗时，不保存原始隐私内容。
