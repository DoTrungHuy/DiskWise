# 文件安全

DiskWise 的原则是：AI 只能提出结构化建议，真正的文件系统操作必须由程序验证并由用户确认。

## 已实现的安全边界

- 扫描目录必须由用户在界面中选择。
- 默认拒绝 Windows 系统目录、磁盘根目录、`Program Files`、`ProgramData`、`Windows` 等位置。
- 扫描时不跟随符号链接和目录联接。
- 计划目标必须位于用户选择的目标目录内，防止路径越界。
- 文件名会过滤 Windows 禁止字符。
- 文件移动和重命名必须传入 `confirmed=True` 才会执行。
- 跨盘移动采用复制、SHA-256 校验、再删除源文件的顺序。
- 删除接口默认使用回收站；未安装 `send2trash` 时会拒绝删除。
- 云端 AI 对 `.env`、密钥文件等敏感文件会直接拒绝。

## 仍需加强

- UI 里还没有暴露批量执行确认按钮。
- 操作日志已建表，后续需要把每次真实操作完整写入并接入撤销页面。
- 计划生成后，执行前还需要加入文件状态二次校验，防止文件已经被外部修改。
- 云端发送前需要更完整的路径脱敏和内容脱敏策略。
